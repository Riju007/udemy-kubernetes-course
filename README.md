# Udemy Kubernetes Course

This repository is a personal learning workspace for the Udemy Kubernetes course:
https://www.udemy.com/course/learn-kubernetes/?couponCode=KEEPLEARNING

## Overview

This project is intended to track notes, exercises, manifests, and hands-on labs as you learn Kubernetes fundamentals and practical deployment workflows.

## What You Will Learn

- Core Kubernetes concepts: pods, deployments, services, ConfigMaps, and Secrets
- Cluster architecture and how Kubernetes components work together
- Deploying and scaling applications in a Kubernetes environment
- Networking, storage, and troubleshooting basics
- Best practices for container orchestration and DevOps workflows

## Repository Purpose

Use this repository to:

- Save lab notes and command snippets
- Store YAML manifests and configuration examples
- Practice Kubernetes deployment workflows
- Track your progress through the course

## Prerequisites

Before starting, make sure you have:

- Basic understanding of containers and Docker
- Access to a Kubernetes environment (local cluster, cloud cluster, or mini-kube setup)
- A terminal and command-line tools such as kubectl

## Suggested Learning Flow

1. Review the course lessons and take notes here.
2. Create small Kubernetes manifests for each topic you learn.
3. Apply them to your cluster and test the results.
4. Refine your understanding by troubleshooting and experimenting.

## Getting Started

Clone the repository and begin adding your exercises:

```bash
git clone <your-repo-url>
cd udemy-kubernetes-course
```

Then create folders for topics such as:

- manifests/
- exercises/
- notes/
- screenshots/

## Notes

This repository is meant to grow with your learning journey. Keep it organized, document what you discover, and use it as a practical reference while working through the course.
